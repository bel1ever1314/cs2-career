# CS2 Career

Windows 上的 CS2 生涯模拟器。用 Python 3 标准库即可运行，不必再装依赖。

## 运行

```
py -3 main.py
```

浏览器会打开本地界面。存档在程序旁边的 `save/`，**不要提交到 GitHub**。

## 怎么玩

- **只玩生涯**：创建档案后用「下一天」推进。正式比赛可以「按实力出战」，不需要 CS2，也不需要任何插件。
- **自己进 CS2 打**：必须另装 **人机增强（CS2 Bot Improver）**。不装就无法进 CS2 游玩。步骤见 [`添加人机增强.txt`](添加人机增强.txt)。
- 进比赛插件 **CareerMatch** 已放在 `vendor/CareerMatch/`，装人机增强时会一并写入游戏。
- 本仓库 **不含** 人机增强本体，也 **不含** 换肤插件。

## 不要上传

- `save/`（生涯进度、Steam 路径、本机目录）
- `__pycache__/`、`.pyc`
- 第三方插件的 `obj/`、`bin/`、`.pdb`
