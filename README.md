# CS2 Career

一个跑在 Windows 上的 CS2 生涯模拟器。

加入一支现役队，或者自己拉个草台班子，从 CCT 一路打到 Major。下一天、转会、发工资、看荣誉墙，这些都不需要打开 CS2。正式比赛点「按实力出战」就行，按选手能力、指挥和心态结算。

想亲自上场也可以。生涯会把你的场次丢进游戏，打完把比分捞回来。这件事必须先装人机增强，本仓库不带那个包，步骤写在 [添加人机增强.txt](添加人机增强.txt)。

换肤这版没有，也不用装。

## 怎么开

已经有 `CS2Career.exe` 的话，双击就行。

从源码跑：

```
py -3 main.py
```

Python 3 即可，不用再 pip 一堆东西。浏览器会自己打开本地页面。存档在旁边的 `save` 文件夹，换电脑把整个文件夹拷走就接着玩。

## 进 CS2 之前先看这句

不加人机增强，进不了 CS2。

生涯本身不受影响。只是想自己开枪的时候，到「训练赛」页填好 Steam、`game\csgo` 和人机增强目录，点「把人机增强装进游戏」，然后把 CS2 彻底关掉再开。装完只切桌面是不够的。

人机增强是别人的项目，请自己去下发行包。进比赛用的 CareerMatch 是这边的，装人机增强时会一起写进游戏。

## 别把这些传上网

`save` 里是你的生涯、Steam 路径和本机目录，不要提交、不要发仓库。缓存、打包出来的 `dist` / `release` 也一样。
