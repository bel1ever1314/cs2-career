1.7.0-preview.1 构建与发布

GitHub 发布源码包和普通 3D Windows 包，标记为 pre-release，保留 1.6.0 正式版。
源码包包括当前生涯内核、Godot 客户端、RTS、资源生成源码、测试及许可。
运行包附带 Python 冻结后台和官方 Godot 运行器，不要求玩家安装开发工具。
Steam、CS2 和完整人机增强由玩家单独安装。组件获取信息见
docs/external-runtime-pins.json。下述整合包仅是原本地候选，不上传 GitHub。

公开归档：
CS2Career-1.7.0-preview.1-source.zip
CS2Career-1.7.0-preview.1-windows.zip
BUILD_MANIFEST.json
SHA256SUMS.txt

运行包内的 source 目录附带本次源码包，可用于审计和二次开发。
完整人机增强的面板不随包分发，不包含私人身份、库存、存档或 Demo。
公开地图/饰品图片和队伍标志保留原始来源，不属于本项目自有版权。
饰品工具只有可选的协议接口，不下载或捆绑外部 3D 检视器。

主要工具：
tools/career3d_package_sources.py：白名单式源码暂存、字体/模型核验。
tools/career3d_package_bots.py：原生和托管组件核验、匿名预设、对应源码。
tools/package_career3d_public.py：从已核对的本地源码/普通运行 ZIP 重封装公开包，
移除整合候选的依赖附件、更新文档、嵌入对应源码，生成最终哈希。
tools/package_career3d.py：冻结后台、导入 Godot 项目、素材复制和三个归档。
tools/career3d_backend_main.py：冻结入口，业务导入仍在独立存档目录选定之后。
tools/career3d_install.py：明确确认安装、关闭游戏检查和覆盖前备份。

重建需要 Python 3.12、PyInstaller、orjson，以及 Godot 4.7.2 Windows 版。
公开重封装使用 package_career3d_public.py 的 --source-zip、--windows-zip、
--project-root 和 --output 参数；--output 是全新公开暂存目录。
以下是原本地完整构建步骤，不能把其整合输出直接作为公开包上传：
先暂存经核验的完整人机增强；打包器的 --bot-stage 指向该暂存结果，
不是 CS2 安装目录。--assets、--fonts、--media-config 明确指定资源输入。
--output 需为全新目录。第一次源码重建可使用源码包中的模型/字体/media。
代码可直接从源码运行，也可用打包脚本冻结。素材目录不要指向私人存档。

发行物需要检查：源码与包内资源完整、无私人路径/数据、配置为相对路径、
冻结后台新存档启动、Godot 脚本导入、客户端与后台连接、三个 ZIP 完整性。
不能把单元测试或开发机启动当成另一台电脑的实机 CS2 兼容验证。
此预览不承诺未来 CS2 更新兼容，测试者需要反馈真实对局问题。

开发记录：715 项完整 Python 测试及 13 项追加包装回归通过，五个场景脚本
检查通过；中文/空格新目录后台启动、接口与客户端连接通过。本轮未启动
真实 CS2 对局。固定 HL2SDK CS2 镜像未找到根级再分发许可，所以公开
暂存排除 legal/bot-runtime 与 third_party/bot-runtime，保留外部获取信息。
原始本地候选归档不覆盖、不删除。
