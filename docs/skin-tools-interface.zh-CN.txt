可选饰品工具接口 v1（3D 版）

这是预留的数据接口，不是内置的 3D 检视器或贴纸编辑器。
程序不捆绑第三方渲染器、模型或网站，不自动下载、运行扩展代码，也没有默认外部地址。
不开启、不安装任何工具，不影响原有市场、开箱、库存和游戏内换肤。

玩家使用
1. 自行取得希望使用的检视／贴纸工具，以及实现下述接口的本地适配器。
2. 在手机／电脑设置中启用“饰品扩展接口”（默认关闭）。
3. 从自己安装的工具操作；本程序不会自动添加或打开第三方编辑界面。
4. 用完可以关闭接口。外部库存仍由外部插件管理，生涯不会覆盖它。
注意：接口已经预留不等于任意工具下载后都会自动兼容，需要工具作者或适配器完成对接。

连接与权限
使用现有 3D 服务的 127.0.0.1 回环地址。
本地适配器可读取本次运行的 runtime/service-<进程号>.json，取得 base_url 和 token。
多个文件同时存在时，不要猜测；让用户选择正在使用的那一份，并确认对应进程仍运行。
所有请求发送 X-Career-Token 请求头。token 不放进 URL，不发送到远程检视网站。
此 token 是整个本地服务的会话凭据，不是“只允许编辑贴纸”的受限令牌。
只将它交给用户信任的本地适配器；不提供给第三方网页脚本。
程序不开放跨站 CORS，不通过此接口代理远程请求或读取任意本机文件。
第三方网页需要一个用户自行安装的本地适配器处理通信，不能直接拿会话凭据调用服务。

接口

GET /api/3d/skin-tools
返回 schema_version=1、enabled、能力和接口地址。
关闭状态也可查询能力说明，但不能读取单件外观或保存贴纸。
不读取完整贴纸目录，不向网站发请求。

GET /api/3d/skin-tools/item?id=<库存实例ID>
开启后读取一件已拥有的饰品。ID 是库存实例 ID，不是市场 skin_id。
返回：schema_version、id、revision、expected_hash、item、model、sticker_catalog、editable、sync。
item 是原生外观数据：武器 def、paint、wear、seed、slot、stickers 等。
model 提供对应武器模型的锚点数量与允许的贴纸位置范围。
sticker_catalog 使用 Valve 贴纸 kit ID，不是第三方网站自己的物品 ID。
仅在显式查询时加载这些数据，不加入手机／电脑每次刷新。
不返回 SteamID、生涯身份、余额、整个库存或比赛数据。

POST /api/3d/skin-tools/stickers
Content-Type: application/json
请求示意（数值只是结构示例，实际 ID 与范围须来自上面的读取结果）：
{
  "schema_version": 1,
  "id": "库存实例ID",
  "revision": 读取结果的revision,
  "expected_hash": "读取结果的expected_hash",
  "stickers": [
    {"slot": 0, "def": 合法贴纸kitID, "schema": 0,
     "wear": 0.0, "rotation": 0.0, "x": 0.0, "y": 0.0}
  ]
}
stickers 是该武器的完整贴纸列表，不是局部补丁；传 [] 表示清除贴纸。
最多五张，槽位 0—4，不能重复。锚点、偏移、旋转和磨损由当前模型目录校验。
只允许上述顶层字段。不能借此改武器涂装、模板、价格、余额、来源或装备状态。
成功返回保存后的 item、expected_hash、新 revision、warnings 和 sync。
保存会保留原有物品来源；不消耗钱，不创建可出售的额外贴纸。
revision 或 expected_hash 过期时拒绝写入。重新读取外观并让用户确认，不盲目覆盖。
未知贴纸／模型、重复槽位、错误坐标、未启用或无效会话均不会改库存。

游戏内表现
生涯库存模式：保存的是生涯外观，下次由现有开赛配装流程同步，不在当前 CS2 对局中强写。
外部库存模式：这里只保存生涯收藏，不回写用户自己的外部库存、插件配置或 Steam 饰品。
外部工具若管理外部库存，应走它自己的插件接口，不能假定生涯保存会更新它。
接口可用不代表已验证所有第三方模型与 CS2 实际贴纸位置一致；工具作者需要实测。

适配建议
外部检视器只拿单件武器的外观和贴纸数据。
若网站使用自己的 ID，适配器明确转换为原生武器 def／paint 与贴纸 kit ID。
在本地完成坐标和锚点映射，再提交合法的完整贴纸列表。
不要把整个生涯 context 或本地服务 token 发送给外部服务。
目前没有随程序提供任意第三方工具的安装包或专用适配器。
