# 赛事竞猜界面整理 + 饰品数量可手输

2026-10-07 · 只改界面，后端接口不变。

## 赛事竞猜

- **头部**
  - 一行放「‹ 赛事中心」、分段标签（可参与 / 我的记录，当前页高亮）和个人余额。
  - 下面一行灰字写规则：只能猜其他队伍的正式 BO、返还含本金、确认后不能撤销。
- **可参与**
  - 「共 N 场可竞猜」，右侧是「推进到下一批对阵 ›」，说明放在悬停提示里。
  - 每场一张卡：赛事·日期·BO，下面并排两个选择按钮「队名 · 押它胜 · ×1.82」，赔率低的一边标「热门」。
  - 点哪边就在这张卡下面展开下注面板，选中的一边绿框高亮。
  - 「A 输」等于「B 胜」，所以页面只问谁赢，提交时固定 `outcome: "win"`，`team_id` 是押的胜方。旧的 `set_outcome("lose")` 仍然可用，会换成押另一边。
- **下注面板**
  - 金额可以手输，也可以点 $100 / $500 / $1,000 / $5,000（超过余额的不显示）或「余额 10%」。
  - 输入时实时显示「猜中返还 / 净赚 / 猜错损失 / 买后余额」，金额不合法时提示范围并禁用「下单」。输入框不会因为重绘丢失焦点。
  - 「下单」后在卡片里出现黄色确认条（再想想 / 确认竞猜），并自动滚动到确认条完整可见。
- **我的记录**
  - 顶部三个数据块：已结算场次、累计返还、本页等待赛果（以及投入金额）。
  - 每条：彩色状态标签（等待赛果 / 命中 / 未命中 / 已退回）、对阵、右侧结果金额（可返还 $X / +$X / -$X / 退回 $X）。
  - 第二行是押谁、投入、赔率、比分，有战报时显示「战报 ›」。
  - 退款原因按当前语言显示。
- **翻页和空状态**
  - 翻页改成「‹ 上一页 1 / N 下一页 ›」。
  - 两个标签页都有空状态说明。

## 饰品购买数量

- 购买面板和暂存行的数量步进器中间改成输入框，可以直接输入数量，回车或点开别处生效。
- 输入会自动限制在 1 到当前上限之间：购买时上限是买得起的件数（最多 100），暂存时上限是持有件数。输入不是数字时保持原数量。
- 上限超过 10 件时，多一个「最多 N」快捷按钮。
