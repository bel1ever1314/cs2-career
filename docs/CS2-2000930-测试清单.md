# CS2 2000930 兼容更新测试清单

适配版本：CS2 1.41.9.0 / 2000930（2026-10-08）。
插件版本：CareerMatch `1.7.2-cs2.2000930.1`。

使用新包的“开始游戏.cmd”启动生涯模式，再由生涯模式进入 CS2。
测试前先保留一份自己的存档备份；新包不带个人存档。

1. **战术导航**：在 Dust2 下达一个短距离路线，再测试连续多个点。
   检查 Bot 是否开始移动、到达目标，并继续后续路线；取消后能恢复自由行动。
2. **观察方向**：给到点保位的 Bot 设置左右两个方向，检查其是否转向、
   视线是否接近水平；随后取消命令，检查它能否重新搜索敌人。
3. **交战优先级**：观察过程中接敌、受伤或投掷道具，检查是否自然接管战斗，
   不会一直盯着旧方向。自己接管 Bot 时应立刻恢复手动操作。
4. **买枪与道具**：检查开局买枪、给队友发枪、投掷物和拆包是否正常。
5. **饰品与头像**：检查换肤、手套、人物模型、队标头像和切换阵营后的显示。
6. **战绩回传**：打完一张图，检查比分、击杀、助攻、接管后的归属；退出 CS2
   后确认能继续系列赛，再换另一张地图检查战术库是否正确切换。

已通过编译与离线回归，导航/观察接口已确认能绑定当前游戏；上述实战结果仍待测试。

另有一个已识别的遗留问题：RayTrace 官方 DLL 与当前 Metamod 的接口不兼容，
它在原运行包中也没有正常启用。本次未强行启用它；CareerMatch 战术导航和
观察方向不依赖它，不能将需要 RayTrace 的额外功能算作已通过。

遇到问题请记录地图、操作步骤、是否接管过 Bot，并保留
`game/csgo/addons/counterstrikesharp/logs` 中对应时间的日志，
以及 `plugins/CareerMatch` 下的战术状态文件。
