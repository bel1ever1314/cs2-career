# 比赛页与生涯推进栏 · 交互整理 · 2026-10-07

针对统一生涯节奏后的比赛页（职业比赛／生涯推进）。只改 3D 客户端展示与按钮分工，后台接口和推进规则不变。

## 分工原则
- **页面正文负责本场比赛的决定**：地图 BP、选择 CT/T 开场、录入 CS2 战绩、CS2 中断后的恢复。
- **底部推进栏负责节奏**：显示当前进行到哪一步和倒计时；提供“模拟第 N 图 / 第 N 图自己打 / 第 N 图 RTS”，以及“暂停 / 自动推进”切换。
- 正文里有待做的决定时，推进栏不再放绿色主按钮，只提示“在上方选择……”，避免两个地方都能点、点了效果却不同。

## 推进栏（career_pace_view.gd）
- 左侧显示状态标题、说明文字和 4 秒倒计时进度条，例如“下一张 · 第 2 图 Train / 4 秒后自动模拟”。
- 按钮写明作用对象：模拟第 2 图、第 2 图自己打、第 2 图 RTS；系列赛结束后是“下一场”。
- 暂停时主按钮立即执行所写的动作；“自动推进”只恢复倒计时，不会立刻执行。
- 已选择亲自上场时，推进栏改为“改为模拟本图 / 改用 RTS”，不再误把绿色按钮变成模拟。
- 页面头部显示“自动推进中 / 已暂停”状态。

## 比赛准备卡（computer_career_match.gd）
- **BP 前**：说明倒计时结束由队长自动 BP 并模拟，旁边放“手动 BP”；列出双方各图评价（你方 : 对手，强弱用颜色区分）。
- **手动 BP**：
  - 每个地图按钮直接标双方评价，横幅显示当前预览图的详细评价；
  - “确认禁用 / 确认选择”和“交给队长完成 BP”放在标题同一行，720p 下无需滚动；
  - 已完成的禁选列成一行。
- **BP 完成后**：
  - 地图横幅统一写明本图状态（本图·谁选的图 / 正在进行·阵营 / CS2 已退出），下面接系列赛地图条，不再重复大标题；
  - 录入战绩、中断恢复按钮紧跟说明，在一屏内；
  - “查看 BP 记录”和“CS2 设置”合成一行。
- **两图之间**：“下一张 · 第 2 图 Train · 系列赛 1:0”和地图评价变化放在战绩表上方。
