# 比赛流程：设置、地图与阵营 · 2026-10-07

起因：朋友试玩时遇到四个问题。①很多设置要退出 CS2、并且打完当前比赛才能保存；②把正在打的图当成了下一张图；③进 CS2 后选错阵营；④比赛地图是 Train，却进了 Nuke，战术用不了。

## 原因

- **设置。** `settings_command` 只要 CS2 在运行，或者有地图在等回传，就拒绝保存。界面每次又会提交全部字段，所以改任何一项都会失败。但每张图开赛时已经把设置冻结在 `career3d_launch` 里，保存设置只写 `cs2.json`，不改游戏文件，这个限制并不需要。
- **地图显示。** 比赛页一直显示“下一图 · X”。正在打、还没录入的那张图仍然是 `pending_map`，于是也显示成“下一图”。
- **地图和阵营要玩家自己选。** 启动 CS2 时不能带 `+map` 参数（会黑屏），所以玩家要在“与机器人游戏 → 竞技”里自己选地图和阵营。
  - 赛事地图和实际游戏地图不同，战绩不能录入原赛事；战术应独立按实际游戏地图选择，不能因此停用。
  - 阵营锁定按固定时间解除，大约开局 33 秒后。加载慢的玩家进来时已经可以选错边。

## 修改

**后端**

`services/activities.py`
- 设置在比赛中、CS2 运行时都可以保存，从下一张图开始生效。
- 只有 CS2 目录在比赛中和 CS2 运行时不能改，因为这张图的战绩要从原目录读取。
- 只比较真正改动的字段，表单里未改动的路径不会触发拦截。
- `settings_context` 新增 `live_match` 和 `apply_note`。

`services/matches.py`
- 新增 `series_maps`，按出场顺序列出每张图。
- 每张图的状态是 `done`、`live`（已进 CS2、等回传）、`next`、`upcoming` 或 `unneeded` 之一。
- 还附带比分（以玩家一方为准）、谁选的图、是否决胜图，以及 live 图的阵营。

`cs2/launch.py`
- 启动提示说明赛事安排的地图；其他地图仍可用对应战术，但不录入本场战绩。
- 开赛和安装时同步所有支持地图的已保存战术库，按地图分文件，同名战术不会串图。
- 关闭 CS2 后可同步任意地图战术，不改比赛请求、阵容、比分或其他地图的战术快照。

**3D 客户端**

- `computer_career_match.gd`
  - 准备卡显示“本图 · 第2图 Train”，CS2 已启动时显示“正在进行 · 第2图 Train”。
  - 下面一行列出全系列：第1图 Mirage 胜 13-9 / 第2图 Train 本图 / 第3图 Nuke 决胜图。
  - 开局按钮写成“CT 开场 · 进入 CS2 打 Train”。
  - 按钮下方提示“与机器人游戏 → 竞技 → 选 Train”。
  - 等回传时提示“CS2 里请打 Train，阵营 T（恐怖分子）”。
  - 不再出现“下一图”。
- `computer_tactics.gd`
  - 比赛日第一次打开战术室时默认进入本场地图。
  - 编辑其他地图时提示赛事安排和当前编辑的地图；进入对应地图即可使用战术，也可一键切回赛事地图。
- `device_settings.gd`：比赛进行中显示“保存后从下一张图开始生效”。

**比赛插件 CareerMatch**（需要重新编译）

- **地图不一致：** 不自动切图，不停用战术。按实际加载地图读取、校验和执行路线；赛事结果仍严格校验请求地图。
- **阵营：** 整个热身期间每秒确认真人在请求的阵营；`mp_human_team` 要等热身真正结束才解除。
- **开局提示：** 真人进入后在聊天里提示“本场地图 de_train · 你在 CT（反恐精英）方开局 · 队名”。
- **聊天颜色码：** 原来的 `\x04CareerMatch` 会被 C# 读成 `\x04Ca`（U+04CA），导致聊天前缀乱码，现改为 `\u0004`。

**本地化**

- `locale_3d_en.txt` 增加新文案的英文。
- `locale_en.json` 由 `tools/build_career3d_locale.py` 重新生成，只新增条目。
