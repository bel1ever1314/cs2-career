# CS2 2000933 兼容更新测试清单

目标版本：CS2 1.41.9.1 / 2000933，SourceRevision 11133601（2026-10-15）。
普通包不含完整人机增强或个人存档；人机增强兼容基线为官方 Bot Improver 1.4.6。

本次更新战术导航与观察方向校验，并使用 BotAimImprover 2.1.6-career1 的 schema 查询替代固定 `m_pBot` 偏移。保留 10 月 12 日首次安装补齐组件、下载失败反馈与重复准备修复。打开设置、保存路径和刷新状态不会下载组件；明确点击外部安装后，仅下载缺失的固定官方组件，校验通过后才写入游戏。

完整实战尚未验证。请备份自己的存档，完全退出 CS2 后安装，再由生涯程序准备本地对局。

1. 初次安装：完整官方 1.4.6 在空缓存下可离线准备；旧包在明确安装后升级缺失组件，原目录不变。网络中断应显示组件与原因，重试复用已校验下载。
2. 重复准备：已安装 CareerMatch 与 gamedata 应复用；瞄准兼容补丁只在安装或明确开赛准备时部署，锁定文件时应停止开赛。
3. 战术导航：短路线、多点连续路线、到点保位与取消后恢复自由行动均需实测。
4. 观察与瞄准：测试左右方向、水平视线、发现敌人、受伤和道具使用；接管 Bot 后应立即恢复手动操作。
5. 其他组件：检查买枪、发枪、投掷物、拆包、饰品和队标头像，以及切换阵营后的表现。
6. 战绩回传：打完一张图，检查比分、击杀、助攻、接管归属和系列赛接续；退出 CS2 后确认普通环境恢复。

RayTrace 官方原生 DLL 的旧 SourceHook 接口限制仍在，不能将其额外功能视为已通过。CareerMatch 的战术导航和观察方向不依赖它。

遇到问题请记录地图、操作步骤和是否接管过 Bot，并保留对应时间的 CounterStrikeSharp 日志与 CareerMatch 战术状态文件。
