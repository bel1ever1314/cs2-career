CS2 Career 1.5｜开始游玩与常见问题
================================

第一次玩，只看前两部分就够了。想亲自进入 CS2 比赛，再看第三部分。
这是公开测试版；如果遇到战绩回传错误，请先保留现场，不要急着重开下一场。

本次新增剧情（stories.1）
恋爱、NA留学生挑战、舆论、队内斗争、伤病和故事档案已加入。
普通生涯在第一场正式比赛后开始恋爱选择；NA挑战在自建页面单独选择，不按真实选手名字触发。
认真职业的选项默认奖励2自由属性点，NA开局额外3点。详见旁边的“剧情扩展说明.txt”。
旧生涯升级会询问是否开启新增剧情，不补演过去的比赛；三种转会告别仍保持各1点的原规则。
程序与测试版分开，正式游玩请启动 CS2Career-StoryArcs.exe（发行压缩包里统一叫CS2Career.exe），
不要误开带 -QA 名字的隔离测试程序。

保留的转会修复（transfer.2）
转会后去邮箱确认写给“新战队”的邀请，再推进赛程；原战队的邀请不再有效。
若从旧转会测试版继续，程序会先备份、重新发新队邀请。已经错过的赛事不会重新打。
签约后仍可以在阵容页切换位置；买人和俱乐部管理不归签约选手支配。
三个告别选项各有后续回应，均发1点技能点且不重复领取。旧版已确认的告别不追溯补发。
本次主要改善加点、页面刷新和赛程推进卡顿；一次结算大量比赛仍可能需要等待。
剧情扩展验证：extensions/_templates/choice-effects-pack/怎么验证.txt。
暂停参赛是玩家明确选择的剧情结果，不是程序坏了：到期会恢复，期间仍能推进日期。

换修复版时：先保存并关闭旧程序和CS2。可把新EXE复制到原EXE同一目录后启动，继续使用旁边的save和extensions。
不要同时开两个版本读写同一份save。也可以把旧目录的整个save及自己启用的扩展包复制到新版本目录；不要覆盖个人扩展。

一、下载与启动
--------------

Q：GitHub 上这么多文件，我应该下载哪个？
A：打开项目的 Releases（发行版）页面：
   https://github.com/bel1ever1314/cs2-career/releases
   下载文件名带 windows-x64.zip 的压缩包，这是普通玩家用的 Windows 版本。
   不要下载 source.zip 或 GitHub 自动提供的 Source code，它们是开发源码。

Q：下载后怎么打开？需要装 Python 吗？
A：把压缩包完整解压到一个自己方便找到、可以写入文件的文件夹。
   双击里面的 CS2Career.exe。不要直接在压缩包里运行。
   使用这个 EXE 不需要安装 Python，也不需要先打开浏览器。
   当前提供 Windows 64 位版本；没有提供 Mac、Linux 或手机版程序。

Q：提示缺少 WebView2，或者窗口打不开怎么办？
A：WebView2 是桌面窗口显示界面所需的微软组件，不是让你改用网页版。
   如果程序提示缺少它，请从微软官网安装适合电脑的 WebView2 Runtime 后重试：
   https://developer.microsoft.com/en-us/microsoft-edge/webview2/
   仍然无法打开，请提供错误截图和版本号，不要反复删除存档。
   若安全软件报警，请先核对下载来源并反馈；不要关闭安全软件或盲目放行。

Q：更新时怎么保留进度？
A：先关闭生涯程序和 CS2，备份旧程序旁边的 save 和 extensions 文件夹。
   把新版解压到新文件夹，再把备份的 save、extensions 复制过去。
   不要用新包里的空文件夹覆盖自己的数据；保留原备份，直到确认能正常读取。
   1.5 的新版存档可继续使用。旧版本存档是否能读取，以程序实际提示为准；
   不支持时不要靠改文件名强行载入，也不要提前删除旧程序和旧存档。

Q：我打开另一个 EXE，为什么生涯没了？
A：存档跟着 EXE 所在文件夹走，保存在旁边的 save 里。
   打开另一个解压目录里的程序，看到的可能就是另一套存档。
   请回到原来的程序目录，或按上面的更新步骤复制自己的存档。

Q：save文件夹越来越大，是所有旧生涯都在吃内存吗？
A：不一定。save/backups里是安全备份，占的是硬盘，不会一起加载进游戏运行内存。
   当前生涯的比赛记录也会随赛季增多而增长，但不能把它当垃圾删掉，否则会丢战报。
   备份优化版以后，新备份使用无损压缩；完全相同的连续快照会复用。
   不自动删除任何旧备份，也不把已有JSON备份转成压缩文件。
   因此更新后主要是新增占用变少，不代表旧文件夹立即变小。

Q：备份里出现season.json.gz、career.json.gz、snapshot.json，是什么？
A：前两项是压缩后的赛季与生涯文件，snapshot.json记录内容校验信息。
   新版程序的失败回滚同时支持旧JSON备份和新压缩备份。
   当前使用的save/season.json、save/career.json仍是普通JSON，不需要你改名。
   如需手动恢复，先关闭程序并另存当前save，再将同一备份目录的两个.gz解压为
   season.json与career.json后成对恢复；不要把.gz直接改扩展名，也不要混用不同时间的两个文件。
   新版产生的待恢复操作，请使用新版程序恢复，不用旧EXE处理中途失败的事务。

二、先玩生涯，不必安装 CS2 插件
-----------------------------

Q：没有打开 CS2，也能玩吗？
A：可以。建档、培养选手、经营、转会、剧情、赛季和模拟比赛都在生涯程序里完成。
   只有选择“自己打”、亲自进入 CS2 时，才需要第三部分的配置。

Q：第一次应该怎么开始？
A：选择年代，再选择接管职业选手，或创建自己的角色。
   自建角色提供路人、青训、天才三种开局，起点不同，不保证必然夺冠。
   先看看首页当前目标、邮箱邀请和比赛日历，再用“下一天”推进。
   遇到需要处理的邀请、合同或剧情，按提示完成后继续。

Q：比赛在哪里？我想看别人的阵容和战绩。
A：从赛程或赛事页面进入比赛；模拟比赛不需要打开 CS2。
   战队名、选手名和比赛记录可以进入对应资料或战报。
   老记录如果只有比分，会注明数据缺失，不会凭空补出十人战绩。

Q：为什么我明明有钱，却买不了皮肤或球员？
A：俱乐部资金和个人余额是两本账。
   买球员、经营球队看俱乐部资金；买饰品、开箱看个人余额。
   饰品详情会显示价格、个人余额或缺多少钱。还不能操作时，检查具体提示。
   如果余额确实够而按钮点不到，请发详情页截图，并说明电脑的显示缩放比例。

Q：工资和奖金要去邮箱领取吗？
A：不用。符合结算条件后会自动入账。
   在经营页看余额和预计下月变化，把鼠标移到相关金额上可查看明细。
   邮箱主要处理邀请、合同和通知，不需要逐封点击领钱。

Q：长期能力、状态和位置有什么区别？
A：能力表示长期水平，状态表示近期起伏，位置影响选手如何发挥。
   不同选手适合的位置可能不同，可以结合比赛表现尝试调整。
   高评分也不保证每张地图都发挥出色；本游戏 Rating 不是 HLTV 官方评分。

Q：开箱要等动画播完才能拿到东西吗？
A：不需要。结果先由程序确定并保存，动画只是展示，可以跳过。
   关闭或跳过动画不会获得重新抽奖的机会。
   所有金额和饰品都是生涯里的虚拟内容，不会进入 Steam 库存，也不能兑现。

三、想亲自进入 CS2 比赛
----------------------

Q：需要额外准备什么？
A：电脑上先安装 Steam 和 CS2，再准备 CS2 Bot Improver 的打包发行文件。
   它是独立的人机增强项目，本生涯包不包含那一整套运行文件。
   从原作者发行页获取 Windows 发行包，不要只下载源码：
   https://github.com/ed0ard/CS2-Bot-Improver/releases
   不同 CS2 更新可能影响插件兼容性；某个上游新版本不代表已经在本生涯里验证过。

Q：三个路径怎么填？
A：先完全退出 CS2，然后打开生涯里的“游戏设置”。
   1. steam.exe：找到 Steam 安装目录里的 steam.exe。
   2. csgo 目录：Steam 中右键 CS2 → 管理 → 浏览本地文件；
      再进入 game 文件夹，再进入 csgo 文件夹，填这个文件夹路径。
      注意：游戏安装目录仍可能叫 Counter-Strike Global Offensive，这是正常的。
   3. 人机增强目录：选择刚解压的人机增强文件夹；里面应能看到 addons 和 overrides。
      不要选压缩包，也不要继续选进 addons 里面。
   点“保存路径”，再点“把人机增强装进游戏”，等待安装完成。
   如果按钮是灰色，先看路径旁的检查结果，并确认 CS2 已彻底关闭。

Q：这些操作会修改 CS2 文件吗？
A：会。安装会把插件和相关文件放进你的 CS2 目录；开赛还会写入本场机器人资料。
   本项目只为生涯本地人机比赛准备，不是普通匹配插件管理器。
   如果原来装过其他 MOD，先按其说明备份；不同 MOD 可能互相覆盖或冲突。

Q：真正进比赛的顺序是什么？
A：保持生涯窗口打开，在自己的比赛页选择“自己打”或进入对应地图。
   程序准备完成后会启动 CS2。按提示进入“与机器人游戏 → 竞技”，
   选择生涯要求的同一张地图，并加入提示的阵营。
   如有提示等待阵容就绪，先等插件准备，不要自行加人、踢人、改队或改赛制。
   不要直接从 Steam 随便开一局，再要求它自动变成生涯比赛。

Q：打到 13 分就可以退出吗？
A：请等游戏正常结束，再切回生涯确认战报已录入。
   不要一看到某方 13 分就立刻退出；加时、终场通知和完整战绩都需要正确处理。
   生涯窗口保持打开时会尝试自动录入；失败时先看完整错误提示。
   不建议手动重启回合、提前退出或擅自切换地图，这可能让战绩无法验证。

Q：为什么下一张图还要求退出 CS2？
A：每场都会根据当前阵容重新准备九名机器人的资料。
   CS2 必须完全关闭再启动，才能读取这场的新资料；只切桌面不算退出。
   修改难度、换阵容、安装或更新插件，也请先关闭 CS2。

Q：Low、Medium、High 怎么选？
A：在生涯的“游戏设置”里选。它们调整人机增强的基础能力；
   具体选手还会按当前生涯能力、位置和状态使用不同个人档位。
   不需要去人机增强的原始选手名单里逐个修改，也不用手动输入内部档案名。
   开着 CS2 时不能修改难度；不同难度的实际体感还会受地图、经济和阵容影响。

Q：接管队友后，战绩算谁的？为什么没聊天提醒？
A：设计规则是：接管后的击杀、伤害和死亡算被接管的那名选手，
   自己原角色在接管前的数据保留。插件不再发送“已接管某某”的聊天提示。
   请以生涯回传战报核对。CS2 自带的 TAB 计分板由游戏维护，可能采用不同显示规则。
   本版接管与回传仍属于重点测试范围，若不符合上述规则请反馈，不要改数字凑结果。

Q：提示“等待回传”“战绩不完整”“身份无法确认”，怎么办？
A：如果比赛还没结束，先正常打完。如果已经结束：
   1. 截下完整错误提示，记住地图、真实比分，以及是否接管过队友。
   2. 可点一次“录入战绩”重试；重试不会自动修复已经缺失的数据。
   3. 仍然失败时不要急着开下一场，避免覆盖这场现场；先反馈问题。
   4. 可提供游戏 game\csgo\addons\counterstrikesharp\plugins\CareerMatch 下的
      match_request.json、match_result.json、match_result.best.json，以及 identity_traces。
   上述文件是排查材料，可能含昵称和本机路径。公开发帖前检查隐私；
   不要把整个 save、账号配置、Steam 登录信息或电脑目录上传到公开 Issue。
   程序不会把缺人战绩补成零，也不会因为只有一个比分就认定比赛有效。

Q：是不是能带着这些插件去官方匹配？
A：不要。本程序只用于由生涯启动的 -insecure 本地人机对局，不用于官方匹配。
   要恢复正常游戏，请先退出生涯和 CS2，按所装 MOD 的说明停用/移除相关插件，
   并检查 Steam 启动项。不保证仅删除 -insecure 或“验证文件完整性”就能移除所有 MOD。
   本项目不承诺任何账号安全豁免；不要把本地测试配置用于官方或联网服务器。

四、换肤、扩展和反馈
------------------

Q：在生涯买了皮肤，为什么 CS2 还是原皮？
A：生涯里的收藏和 CS2 本地换肤是两回事，换肤是可选功能。
   先安装人机增强，再在“游戏设置”点“把换肤插件装进游戏”。
   本程序自带换肤插件，换肤插件目录一般可留空。
   勾选“启用游戏内换肤”，填写自己的 17 位 SteamID，保存换肤偏好；
   在收藏里分别给 CT、T 装备想用的饰品，再完全退出 CS2 后重新进入。
   SteamID 不是昵称、密码或登录验证码；程序不需要你的 Steam 密码。

Q：CS2 更新后换肤失效怎么办？
A：先关闭 CS2，可在“游戏设置”尝试“更新换肤签名”，然后重新进游戏。
   这个按钮更新的是兼容数据，不会自动更新所有插件，也不能保证修好所有游戏更新问题。
   失败时保留提示并反馈，暂时关闭游戏内换肤仍可继续玩生涯。

Q：饰品图片没显示怎么办？
A：部分图片需要联网获取；断网时会优先用已缓存图片，没有缓存就显示占位图。
   缺图不等于物品丢失。请以库存里的物品名称、磨损和装备状态为准。

Q：剧情包、赛事包、皮肤包放哪里？
A：放在 EXE 旁边的 extensions 文件夹里，每个包独立一个文件夹。
   不要多套一层同名文件夹；关闭程序后安装，再重新打开查看扩展工坊。
   _templates 是制作示例，不是把任意图片或压缩包丢进去就能生效。
   不需要扩展也能正常玩。制作扩展的详细说明在 GitHub 源码中，普通玩家不用读开发文档。
   只使用信任来源的扩展；安装前备份，不要用来源不明的 EXE 当“剧情包”运行。

Q：在哪里提问题？应该提供什么？
A：https://github.com/bel1ever1314/cs2-career/issues
   请写：版本号、你做了什么、预期结果、实际结果、错误截图。
   CS2 对局问题额外说明地图、真实比分、是否换边/接管/重启过回合。
   这有助于复现问题，比只说“坏了”更容易排查。

Q：这个项目和 Valve、战队或选手有官方关系吗？
A：没有。本项目是非官方生涯模拟器。名字、商标和饰品美术属于相应权利人。
   生涯代码采用 AGPL-3.0-only，第三方使用各自的授权。
   修改和分发的说明见源码仓库；相关授权随包保留在 LICENSE 和 licenses 中。
【新增：我能去其他战队吗？】
个人转会测试版新增“转会市场 → 我的转会”，战队详情也可以点“申请加盟”。
申请采用 D20 骰点加位置能力修正，页面会提前显示成功率；成功后仍可选择加盟或留下。
失败后30天不能申请任何队、同队90天；申请成功后90天不能再申请；正式加盟后180天不能再转会。
其他球队每年最多主动发来4份补强邀约，不保证发满，邮箱邀约无需掷骰，有效30天。
自建队离开后改为签约选手。个人钱、饰品、能力与荣誉跟你走，原队金库和银行债务不跟你走。
原队继续参加比赛，由管理层补齐阵容并经营；你不再有买人、改全队位置或解散俱乐部的权限。
个人借款不会因为转会免除。正式比赛、已准备的训练赛或重要待决剧情未结束时，请先处理完再申请。
想自己写转会剧情：看 extensions/_templates/transfer-story-pack 里的“怎么写与验证.txt”。
